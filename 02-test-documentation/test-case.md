
# Test Cases

## 1. Introduction
This document contains detailed test cases
based on verified website features.

## 2. Test Case Template

| Field | Description |
|---|---|
| Test Case ID | Unique test case identifier |
| Scenario ID | Related test scenario |
| Test Objective | Purpose of the test |
| Preconditions | Required conditions |
| Test Steps | Steps performed by tester |
| Test Data | Input used |
| Expected Result | Expected system behavior |
| Actual Result | Actual system behavior |
| Status | Pass / Fail / Blocked |
| Evidence | Screenshot reference |

## 3. Example Test Case

### TC-001: Main Navigation

- Scenario ID: TS-001
- Objective: Verify main navigation links.
- Preconditions: Website is accessible.
- Test Steps:
  1. Open the website.
  2. Select an available navigation menu.
  3. Observe the destination page.

- Expected Result:
  The system opens the correct destination page.

- Actual Result: Pending
- Status: Not Tested
- Evidence: Not Available

## 4. Notes
Actual results must only be recorded after
the test has been performed.
