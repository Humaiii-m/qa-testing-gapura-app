# qa-testing-gapura-app
Quality Assurance Testing Project – Functional Testing of Gapura App using Black Box Testing, Equivalence Partitioning, and Boundary Value Analysis.

## Project Overview
This project focuses on functional quality testing
of Gapura App using the Black Box Testing method.

## Project Title
Pengujian Kualitas Fungsional Aplikasi Gapura App
Menggunakan Metode Black Box Testing dengan Teknik
Equivalence Partitioning dan Boundary Value Analysis.

## Testing Method
- Black Box Testing
- Equivalence Partitioning
- Boundary Value Analysis

## Project Objectives
1. Identify functional defects.
2. Evaluate system behavior based on test scenarios.
3. Document test results and evidence.
4. Provide recommendations for improvement.
