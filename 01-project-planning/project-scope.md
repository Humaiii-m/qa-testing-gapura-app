
# Project Scope

## 1. Project Title
Pengujian Kualitas Fungsional Aplikasi Gapura App
Menggunakan Metode Black Box Testing dengan Teknik
Equivalence Partitioning dan Boundary Value Analysis.

## 2. Testing Object
Nama: Gapura App
Website: https://gapuraapp.com/

Status objek: Candidate - Pending Validation

## 3. Project Objectives
1. Mengidentifikasi kesalahan fungsional pada sistem.
2. Menguji kesesuaian fungsi dengan hasil yang diharapkan.
3. Mendokumentasikan hasil pengujian.
4. Memberikan rekomendasi perbaikan.

## 4. Testing Scope
Pengujian akan difokuskan pada fungsi yang benar-benar
tersedia dan dapat diakses pada website.

Contoh area yang akan diperiksa:
- Navigasi website.
- Pencarian dan kategori.
- Informasi UMKM.
- Detail produk atau toko.
- Formulir dan validasi input, jika tersedia.

## 5. Out of Scope
- Pengujian keamanan secara mendalam.
- Pengujian source code internal.
- Pengujian infrastruktur server.
- Pengujian beban skala besar.

## 6. Testing Method
Black Box Testing.

Teknik:
- Equivalence Partitioning.
- Boundary Value Analysis.

## 7. Project Duration
5 Weeks

## 8. Limitations
Pengujian dibatasi pada fitur yang dapat diakses
oleh anggota kelompok selama periode penelitian.
