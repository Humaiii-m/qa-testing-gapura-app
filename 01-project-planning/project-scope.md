# Project Scope

## 1. Project Title

Pengujian Kualitas Fungsional Aplikasi Gapura App Menggunakan Metode Black Box Testing dengan Teknik Equivalence Partitioning dan Boundary Value Analysis.

## 2. Testing Object

- Nama Aplikasi: Gapura App
- Website: https://gapuraapp.com/umkm
- Jenis Aplikasi: Web Application
- Status Objek: Selected - Exploration Completed

## 3. Project Objectives

1. Mengidentifikasi kesalahan atau defect pada fungsi website Gapura App.
2. Menguji kesesuaian fungsi aplikasi dengan hasil yang diharapkan.
3. Menerapkan teknik Equivalence Partitioning dan Boundary Value Analysis dalam pengujian fungsional.
4. Melakukan pengujian melalui pendekatan Manual Testing dan Automation Testing menggunakan Selenium.
5. Membandingkan hasil pengujian manual dan otomatis.
6. Mendokumentasikan hasil pengujian dan memberikan rekomendasi perbaikan.

## 4. Testing Scope

Pengujian difokuskan pada fungsi-fungsi website Gapura App yang dapat diakses dan digunakan selama periode penelitian.

Berdasarkan eksplorasi awal, area yang menjadi kandidat pengujian meliputi:

### A. Fitur Pengunjung

- Navigasi halaman website.
- Menampilkan daftar UMKM.
- Pencarian UMKM atau produk.
- Filter kategori UMKM.
- Menampilkan detail toko.
- Menampilkan informasi produk.
- Tombol pemesanan yang mengarahkan pengguna ke WhatsApp.

### B. Fitur Pemilik Toko

- Login pengguna.
- Pembuatan toko.
- Menampilkan dashboard pemilik toko.
- Melengkapi dan mengubah profil toko.
- Validasi input pada formulir profil.
- Menambahkan produk.
- Mengelola informasi produk, sesuai fitur yang tersedia.

### C. Aspek Pengujian

- Kesesuaian fungsi dengan hasil yang diharapkan.
- Validasi input pada formulir.
- Penanganan input valid dan tidak valid.
- Pengujian batas nilai input menggunakan Boundary Value Analysis.
- Pengujian kelompok input menggunakan Equivalence Partitioning.
- Kesesuaian hasil pengujian manual dan otomatis.

Catatan: daftar fitur di atas merupakan kandidat ruang lingkup berdasarkan eksplorasi. Fitur final yang diuji akan ditetapkan berdasarkan akses, relevansi terhadap tujuan penelitian, dan kelayakan pengujian.

## 5. Out of Scope

Pengujian tidak mencakup:

- Pengujian keamanan secara mendalam (penetration testing).
- Pengujian source code internal.
- Pengujian infrastruktur dan konfigurasi server.
- Pengujian beban skala besar (large-scale load testing).
- Proses transaksi, pembayaran, dan komunikasi lanjutan yang berlangsung di luar Gapura App melalui WhatsApp.
- Pengujian sistem internal WhatsApp.

## 6. Testing Method and Techniques

### Testing Method
- Black Box Testing.

### Testing Techniques
- Equivalence Partitioning (EP).
- Boundary Value Analysis (BVA).

### Testing Approaches
- Manual Testing.
- Automation Testing menggunakan Selenium.

## 7. Project Duration

- Initial Project Duration: 5 Weeks
- Remaining Project Duration: 4 Weeks

## 8. Limitations

- Pengujian dibatasi pada fitur yang dapat diakses oleh anggota kelompok selama periode penelitian.
- Pengujian dilakukan berdasarkan perilaku aplikasi dari sisi pengguna tanpa memeriksa source code internal.
- Hasil pengujian bergantung pada kondisi website, ketersediaan akun, dan lingkungan pengujian.
- Pengujian otomatis menggunakan Selenium dibatasi pada fitur yang memungkinkan untuk diotomatisasi melalui browser.
- Perubahan pada website selama periode penelitian dapat memengaruhi hasil pengujian.

## 9. Scope Finalization

Ruang lingkup final akan ditetapkan setelah analisis fitur dan penyusunan Test Plan selesai dilakukan.
