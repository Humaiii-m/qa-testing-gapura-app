# Project Overview

## 1. Project Name

QA Testing - Gapura App

## 2. Project Description

Proyek ini berfokus pada pengujian kualitas fungsional website Gapura App, yaitu platform yang menyediakan katalog dan etalase digital bagi pelaku Usaha Mikro, Kecil, dan Menengah (UMKM).

Pengujian dilakukan untuk memeriksa apakah fitur-fitur yang tersedia pada website berjalan sesuai dengan fungsi yang diharapkan.

Proyek ini menggunakan metode Black Box Testing dengan teknik Equivalence Partitioning dan Boundary Value Analysis. Pengujian akan dilakukan melalui dua pendekatan, yaitu Manual Testing dan Automation Testing menggunakan Selenium.

## 3. Testing Object

- Application: Gapura App
- Website: https://gapuraapp.com/umkm
- Application Type: Web Application
- Testing Focus: Functional Testing

## 4. Testing Method and Techniques

**Testing Method:**
- Black Box Testing

**Testing Techniques:**
- Equivalence Partitioning (EP)
- Boundary Value Analysis (BVA)

**Testing Approaches:**
- Manual Testing
- Automation Testing menggunakan Selenium

## 5. Project Objectives

1. Mengidentifikasi kesalahan atau defect pada fungsi website Gapura App.
2. Mengevaluasi kesesuaian fungsi aplikasi dengan hasil yang diharapkan.
3. Menerapkan teknik Equivalence Partitioning dan Boundary Value Analysis dalam perancangan pengujian.
4. Melakukan pengujian secara manual dan otomatis menggunakan Selenium.
5. Membandingkan hasil pelaksanaan pengujian manual dan otomatis.
6. Mendokumentasikan hasil pengujian serta memberikan rekomendasi perbaikan.
