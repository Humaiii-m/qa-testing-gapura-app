# Testing Schedule

Project Duration: 4 Remaining Weeks

## Completed Activities
- Initial project planning.
- Testing object selection.
- Gapura App validation and approval by lecturer.

## Remaining Schedule

| Week | Focus | Activities | Deliverables |
|---|---|---|---|
| Week 1 | Standards Research & Test Planning | Review ISO/IEEE standards, conduct relevant literature research, finalize test plan, and prepare documentation templates | Verified references, finalized test plan, and documentation templates |
| Week 2 | Test Design | Finalize test items, test scenarios, test cases, test data, and prepare manual and Selenium testing procedures | Final test scenarios, test cases, and test data |
| Week 3 | Test Execution | Execute manual testing and Selenium testing, collect evidence, document defects, and conduct QA interview | Test results, test evidence, bug reports, and interview documentation |
| Week 4 | Analysis & Finalization | Perform retesting, compare manual and Selenium results, analyze findings, formulate recommendations, and prepare final report and presentation | Final testing report, presentation, and completed GitHub repository |

## Immediate Target

By the end of Week 1:

1. Complete relevant ISO/IEEE standards research.
2. Finalize the Test Plan.
3. Prepare testing documentation templates.
4. Review and push completed documents to GitHub.

## Progress Tracking

All team members must document their contributions through GitHub commits and weekly progress updates.
