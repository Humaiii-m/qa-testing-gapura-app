# Test Evidence – Gapura App

## TC-001 – Akses Halaman Beranda

- **Modul:** Beranda
- **Jenis pengujian:** Functional / Black Box Testing
- **Langkah pengujian:** Membuka URL `https://gapuraapp.com/` melalui browser.
- **Hasil yang diharapkan:** Halaman beranda Gapura App berhasil ditampilkan dan elemen utama seperti logo, navigasi Beranda/UMKM/Tentang Kami, tombol Buat Toko, serta kolom pencarian terlihat.
- **Hasil aktual:** Berdasarkan screenshot, halaman beranda berhasil dimuat. Logo Gapura, menu navigasi, tombol Buat Toko, judul halaman, dan kolom pencarian terlihat.
- **Status:** PASS (berdasarkan tampilan yang terlihat pada screenshot)
- **Evidence:** `TC-001_homepage.png`

> Catatan: Bukti ini hanya mendukung pengujian akses dan tampilan awal halaman beranda. Pengujian fungsi pencarian, tombol Buat Toko, dan menu navigasi perlu dilakukan terpisah.
