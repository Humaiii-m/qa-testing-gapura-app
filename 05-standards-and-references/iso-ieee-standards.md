
# ISO/IEC/IEEE Standards

## 1. Deskripsi

Bagian ini mendokumentasikan standar internasional yang menjadi referensi dalam pelaksanaan proyek pengujian kualitas fungsional Gapura App.

Standar digunakan sebagai landasan untuk memahami konsep, proses, teknik, dan dokumentasi pengujian perangkat lunak.

## 2. Daftar Standar

| No. | Nomor Standar | Tahun | Judul | Status |
|---|---|---|---|---|
| 1 | ISO/IEC/IEEE 29119-1 | 2022 | Software and Systems Engineering — Software Testing — Part 1: General Concepts | Dokumen tersedia |

## 3. Ringkasan Standar

### ISO/IEC/IEEE 29119-1:2022

**Judul:** Software and Systems Engineering — Software Testing — Part 1: General Concepts.

**Edisi:** Kedua (2022).

**Ruang Lingkup:**

Standar ini menjelaskan konsep umum dalam pengujian perangkat lunak dan memperkenalkan konsep utama yang digunakan dalam seri standar ISO/IEC/IEEE 29119.

**Pokok Pembahasan:**

1. Konsep dasar software testing.
2. Hubungan Quality Assurance (QA), Quality Control (QC), dan testing.
3. Verification dan Validation.
4. Static Testing dan Dynamic Testing.
5. Test Plan dan Test Strategy.
6. Risk-Based Testing.
7. Test Levels dan Test Types.
8. Test Design Techniques.
9. Manual Testing dan Automated Testing.
10. Test Documentation.
11. Defect and Incident Management.

## 4. Relevansi terhadap Proyek

Judul Proyek:

Pengujian Kualitas Fungsional Aplikasi Gapura App Menggunakan Metode Black Box Testing dengan Teknik Equivalence Partitioning dan Boundary Value Analysis.

Standar ISO/IEC/IEEE 29119-1:2022 digunakan sebagai referensi konseptual untuk memahami dan merencanakan aktivitas pengujian.

Penerapan yang direncanakan dalam proyek:

| Konsep Standar | Penerapan dalam Proyek |
|---|---|
| Test Planning | Menentukan tujuan dan ruang lingkup pengujian Gapura App |
| Risk-Based Testing | Mempertimbangkan risiko dan prioritas fitur yang diuji |
| Test Design Techniques | Merancang pengujian menggunakan Equivalence Partitioning dan Boundary Value Analysis |
| Test Execution | Melakukan pengujian secara manual dan otomatis menggunakan Selenium |
| Test Documentation | Mendokumentasikan test case, hasil pengujian, dan bukti |
| Defect Management | Mencatat dan mengelola bug yang ditemukan |

## 5. Catatan Penerapan

ISO/IEC/IEEE 29119-1:2022 merupakan standar informatif yang memberikan konsep dan panduan umum pengujian perangkat lunak.

Penerapannya dalam proyek ini disesuaikan dengan ruang lingkup penelitian, kemampuan tim, serta akses terhadap aplikasi Gapura App.

Pemetaan di atas merupakan rencana penerapan awal. Implementasi aktual akan disesuaikan setelah aktivitas pengujian dilaksanakan.
