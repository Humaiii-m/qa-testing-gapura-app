# Journal References

## 1. Pendahuluan

Dokumen ini berisi daftar referensi jurnal ilmiah yang digunakan sebagai landasan teori dan pendukung dalam proyek:

**Pengujian Kualitas Fungsional Aplikasi Gapura App Menggunakan Metode Black Box Testing dengan Teknik Equivalence Partitioning dan Boundary Value Analysis.**

Referensi jurnal digunakan untuk mendukung pembahasan mengenai:

- Black Box Testing.
- Equivalence Partitioning (EP).
- Boundary Value Analysis (BVA).
- Perancangan dan pelaksanaan test case.
- Manual Testing dan Automation Testing.
- Penggunaan Selenium WebDriver.
- Perbandingan teknik dan tools pengujian perangkat lunak.

## 2. Daftar Referensi Jurnal

### 2.1 Black Box Testing, Equivalence Partitioning, dan Boundary Value Analysis

**[1] Implementasi Black Box Testing pada Aplikasi Sistem Kasir dengan Menggunakan Teknik Equivalence Partitions**

- Penulis: Muhammad Nurul Huda, Muhammad Burhan, Ahmad Satibi, Helmy Agus Pradita, Aries Saifudin, dan Irpan Kusyadi.
- Tahun: 2022.
- Jurnal: Jurnal Teknologi Sistem Informasi dan Aplikasi.
- Volume: 5, Nomor 2, halaman 120–127.
- DOI: https://doi.org/10.32493/jtsi.v5i2.17645
- Relevansi: Menjadi referensi penerapan Black Box Testing dengan teknik Equivalence Partitioning pada aplikasi sistem kasir, khususnya dalam pengelompokan input valid dan tidak valid.

**[2] Perbandingan Metode Equivalence Partitions dan Boundary Value Analysis pada Pengujian Black Box (Literature Review)**

- Penulis: Firman Dwi Hartono dan Yuni Sugiarti.

- Relevansi: Menjadi referensi teoritis untuk memahami konsep, kelebihan, kekurangan, dan penerapan Equivalence Partitioning serta Boundary Value Analysis dalam pengujian Black Box.

**[3] Black Box Testing pada Website Sistem Perpustakaan Menggunakan Metode Equivalence Partitioning dan Analisis Boundary Value**

**[4] Black Box Testing Website Rima Batik dengan Teknik Boundary Value dan Equivalence Partitioning**

## 4. Penerapan Referensi dalam Proyek Gapura App

Referensi jurnal digunakan sebagai landasan dalam menyusun dan melaksanakan pengujian pada Gapura App.

Penerapan dalam proyek meliputi:

1. Menggunakan pendekatan Black Box Testing untuk menguji fungsi aplikasi dari sisi pengguna.
2. Menggunakan Equivalence Partitioning untuk mengelompokkan data input ke dalam kelas valid dan tidak valid.
3. Menggunakan Boundary Value Analysis untuk menguji nilai pada batas minimum dan maksimum input.
4. Menyusun test scenario, test case, test data, dan expected result berdasarkan fitur yang diuji.
5. Melaksanakan pengujian secara manual dan otomatis menggunakan Selenium WebDriver.
6. Membandingkan hasil pengujian manual dan otomatis berdasarkan hasil eksekusi, waktu pengujian, serta temuan kesalahan.
